# BNJ TPV OVERLAY

Logiciel d'affichage de données personnalisables pour TrainingPeaks Virtual.

## Fonctionnalités

- Affichage des données de course
- Compteur GPS personnalisable en 3D
- Indicateur de vent
- Presets de caméra
- Personnalisation de l'interface
